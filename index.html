Flow VPN Client — Support

Flow is a VPN client for iPhone. It connects to VPN servers using a subscription link, a server link or a server configuration from a provider of your choice, and supports the VLESS, VMess, Trojan, Shadowsocks, Hysteria2 and AmneziaWG protocols. The app has no servers of its own, no account and no purchases.

Contact us

Questions about the app: support@nalitek.com. We reply in English and Russian.

Before you write

  • The subscription does not load or has ended. Subscriptions and servers come from your subscription provider — whoever gave you the link. Please contact them: we have no access to subscriptions or servers. To check whether the subscription has changed, tap “Refresh now” on the “Profiles” screen (it is below the profile list when the active profile is a subscription) — or “Check again” if the home screen says “Subscription expired”. If you have another profile, switch to it with the “Profiles” button.
  • The VPN does not connect. Choose another server: tap “Server” on the home screen, or “Try another server” on the error screen. The error screen also has a “Profiles” button: choose another profile or delete the one that does not work.
  • Send us the error log. Settings → About → Error log → Copy, then paste the text into your email. The log contains no server addresses and no subscription link — they are replaced with placeholders.
  • Tell us the app version: Settings → About → Version, plus your iPhone model and iOS version.

Profiles

Each subscription and each server you added on its own — with a link or a configuration — is a profile. One profile is active: the VPN connects to its server. The list of profiles is on the “Profiles” screen: tap “Profile” on the home screen.

  • How to add one. On the “Profiles” screen tap “Add profile”. Paste a subscription link or a server link into the field and tap “Save”. To add a server configuration, tap “Paste from clipboard” or “Import configuration file”. The new profile becomes active at once; if the VPN is on, the connection moves to its server.
  • From another app. A configuration file (.conf) can be shared to Flow from Files, Mail or a messenger: open the Share sheet and choose Flow. The server is added as a new profile, and the app shows “Servers added: 1”. No connection is started, and if you already had profiles, the active one stays the same — choose the new profile in the list. At first launch, the server is added after you tap “Understood” on the “What data we use” screen.
  • How to switch. Tap a profile in the list — the active one has a check mark. If the VPN is on, the connection moves to that profile’s server; you do not need to turn the VPN off. The profile also changes when you pick a server of another profile on the “Servers” screen.
  • How to delete one. Tap the trash icon in the profile’s row and confirm with “Delete profile”. The profile is removed from this iPhone: a subscription together with its servers, a server together with its keys. Deleting the active profile while the VPN is on turns the VPN off.
  • “Subscription expired”. The home screen looks like this only when the active profile’s subscription has ended. Your other profiles are not affected: tap “Profiles” and choose another one. In the profile list, such a subscription has “expired” under its name.

AmneziaWG servers

An AmneziaWG server is added from a configuration — a text or a file issued by your provider. No camera is needed for this.

  • From the clipboard. Copy the whole configuration text and tap “Paste from clipboard”.
  • From a file. Tap “Import configuration file” and pick the file in the Files window.
  • Where the buttons are. On the “Subscription link” screen at first launch, and in the “Add profile” window: tap “Profile” on the home screen, then “Add profile”.
  • With the Share sheet. A configuration file can be shared to Flow from another app — see “Profiles” above.
  • What happens next. The server becomes a profile of its own. On the “Servers” screen it is in the “Added manually” section, with the caption “AmneziaWG” under its name. Configuration text cannot be pasted into the link field: use the buttons.

If the configuration was not added

The app shows one of these messages:

  • “This configuration isn’t supported”. The configuration has a parameter or a value that this version of the app does not accept. Contact the provider that issued it.
  • “The configuration is damaged or incomplete”. The text was not copied in full or was changed: a required line is missing, or a key or an address is written incorrectly. Copy the whole configuration again, or import the file.
  • “Too large to be a server configuration”. The text or the file is larger than 64 KB — it is not a server configuration.
  • “This file doesn’t contain a server configuration”. A different file was picked or shared: it is empty, it is not text, or it has no configuration in it. Server links cannot be added from a file — paste them into the link field.
  • “Couldn’t read the file”. The file did not open. Pick or share it again.
  • “To add a server configuration, tap “Paste from clipboard” or import a file”. Configuration text ended up in the link field. The field is cleared; add the configuration with a button.

How an AmneziaWG server differs from the others

  • The “.ru sites go direct” switch is inactive. It is the first switch in the “Connection” section of Settings. While an AmneziaWG server is selected, it cannot be toggled: what goes through the VPN is set by the server’s configuration. The setting keeps its value and applies again when a server of another protocol is selected.
  • Measure shows “—”. While the VPN is off, the latency of an AmneziaWG server is not measured. While the VPN is on, it is measured only if the server’s configuration routes all internet addresses (IPv4 and IPv6) through the VPN; otherwise “—” stays.
  • The server stopped responding. The VPN does not turn itself off. The app does not notice it at once: the status stays “Connected” for up to a few minutes, and if the configuration has no PersistentKeepalive line — until the network changes or the iPhone wakes up. Then the home screen shows “Connecting”, and the app keeps retrying until the server responds. Connections that go through the VPN do not work all this time. To leave this state, tap the circle on the home screen — the VPN disconnects. Then choose another server or contact the provider that issued the configuration.

Flow VPN Client — поддержка

Flow — VPN-клиент для iPhone. Он подключается к VPN-серверам по ссылке подписки, по ссылке на сервер или по конфигурации сервера от поставщика, которого вы выбрали сами, и поддерживает протоколы VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и AmneziaWG. В приложении нет своих серверов, учётной записи и покупок.

Связаться с нами

Вопросы о приложении: support@nalitek.com. Отвечаем на русском и английском.

Прежде чем писать

  • Подписка не загружается или закончилась. Подписку и серверы выдаёт поставщик подписки — тот, кто дал вам ссылку. Обратитесь к нему: у нас нет доступа к подпискам и серверам. Проверить, не изменилась ли подписка, можно кнопкой «Обновить сейчас» на экране «Профили» (она под списком профилей, когда активный профиль — подписка), а если на главном экране написано «Подписка закончилась» — кнопкой «Проверить снова». Если у вас есть другой профиль, перейдите на него кнопкой «Профили».
  • VPN не подключается. Выберите другой сервер: на главном экране нажмите «Сервер» или на экране ошибки — «Попробовать другой сервер». На экране ошибки есть и кнопка «Профили»: выберите другой профиль или удалите тот, что не работает.
  • Пришлите журнал ошибок. «Настройки → О приложении → Журнал ошибок → Копировать» — и вставьте текст в письмо. Адресов серверов и ссылки подписки в журнале нет: их заменяют метки.
  • Укажите версию приложения: «Настройки → О приложении → Версия», а также модель iPhone и версию iOS.

Профили

Каждая подписка и каждый сервер, который вы добавили отдельно — ссылкой или конфигурацией, — это профиль. Активен один профиль: к его серверу подключается VPN. Список профилей — на экране «Профили»: на главном экране нажмите «Профиль».

  • Как добавить. На экране «Профили» нажмите «Добавить профиль». Ссылку подписки или ссылку на сервер вставьте в поле и нажмите «Сохранить». Конфигурацию сервера добавьте кнопкой «Вставить из буфера» или «Импортировать файл конфигурации». Добавленный профиль сразу становится активным; если VPN включён, подключение переходит на его сервер.
  • Из другого приложения. Файл конфигурации (.conf) можно передать в Flow из «Файлов», почты или мессенджера: откройте «Поделиться» и выберите Flow. Сервер добавится новым профилем, приложение покажет «Добавлено серверов: 1». Подключение при этом не начинается, а если профили уже были, активным остаётся прежний — выберите новый профиль в списке. При первом запуске сервер добавится после того, как вы нажмёте «Понятно» на экране «Какие данные мы используем».
  • Как переключиться. Нажмите на профиль в списке — у активного стоит галочка. Если VPN включён, подключение переходит на сервер этого профиля, выключать VPN не нужно. Профиль меняется и тогда, когда вы выбираете сервер другого профиля на экране «Серверы».
  • Как удалить. Нажмите значок корзины в строке профиля и подтвердите кнопкой «Удалить профиль». Профиль удаляется с этого iPhone: подписка — вместе со своими серверами, сервер — вместе со своими ключами. Если удалить активный профиль при включённом VPN, VPN отключится.
  • «Подписка закончилась». Так главный экран выглядит, только когда закончилась подписка активного профиля. Другим профилям это не мешает: нажмите «Профили» и выберите другой. В списке профилей под названием такой подписки написано «закончилась».

Сервер AmneziaWG

Сервер AmneziaWG добавляется из конфигурации — текста или файла, который выдал ваш поставщик. Камера для этого не нужна.

  • Из буфера обмена. Скопируйте текст конфигурации целиком и нажмите «Вставить из буфера».
  • Из файла. Нажмите «Импортировать файл конфигурации» и выберите файл в окне «Файлы».
  • Где эти кнопки. На экране «Ссылка подписки» при первом запуске и в окне «Добавить профиль»: на главном экране нажмите «Профиль», затем «Добавить профиль».
  • Через «Поделиться». Файл конфигурации можно передать в Flow из другого приложения — раздел «Профили» выше.
  • Что будет дальше. Сервер становится отдельным профилем. На экране «Серверы» он стоит в разделе «Добавлены вручную», под его именем — подпись «AmneziaWG». В поле для ссылки текст конфигурации не вставляется: пользуйтесь кнопками.

Если конфигурация не добавилась

Приложение покажет одну из фраз:

  • «Эта конфигурация не поддерживается». В конфигурации есть параметр или значение, которые эта версия приложения не принимает. Обратитесь к поставщику, который её выдал.
  • «Конфигурация повреждена или неполная». Текст скопирован не целиком или изменён: не хватает обязательной строки, либо ключ или адрес записан с ошибкой. Скопируйте конфигурацию заново, целиком, или импортируйте файл.
  • «Слишком большой размер для конфигурации сервера». Текст или файл больше 64 КБ — это не конфигурация сервера.
  • «В файле нет конфигурации сервера». Выбран или передан другой файл: он пуст, это не текст или в нём нет конфигурации. Ссылки на серверы файлом не добавляются — вставьте их в поле для ссылки.
  • «Не удалось прочитать файл». Файл не открылся. Выберите или передайте его ещё раз.
  • «Чтобы добавить конфигурацию сервера, нажмите «Вставить из буфера» или импортируйте файл». Текст конфигурации оказался в поле для ссылки. Поле очищается; добавьте конфигурацию кнопкой.

Чем сервер AmneziaWG отличается от остальных

  • Переключатель, который направляет часть сайтов напрямую, неактивен. Это первый переключатель в разделе «Подключение» настроек. Пока выбран сервер AmneziaWG, он не нажимается: что идёт через VPN, задаёт конфигурация сервера. Значение настройки сохраняется и снова действует, когда выбран сервер другого протокола.
  • «Измерить» показывает «—». При выключенном VPN задержка сервера AmneziaWG не измеряется. При включённом VPN она измеряется, только если конфигурация сервера направляет через VPN все адреса интернета (IPv4 и IPv6); иначе остаётся «—».
  • Сервер перестал отвечать. VPN при этом сам не выключается. Приложение замечает это не сразу: до нескольких минут статус остаётся «Подключено», а если в конфигурации нет строки PersistentKeepalive — до смены сети или пробуждения iPhone. Затем статус — «Подключаемся», и приложение повторяет попытки, пока сервер не ответит. Соединения, которые идут через VPN, всё это время не работают. Чтобы выйти, нажмите на знак на главном экране — VPN отключится. Затем выберите другой сервер или обратитесь к поставщику, который выдал конфигурацию.
